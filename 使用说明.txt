ScreenStay —— 智能屏幕常亮小工具（v1.5.3）
==========================================

安装与卸载
----------
· 普通用户：双击 ScreenStay-Setup-1.5.2.exe，按向导安装（默认安装到
  %LOCALAPPDATA%\Programs\ScreenStay）。
· 安装后可在「设置 → 应用 → 已安装的应用」或控制面板「程序和功能」中
  直接卸载 ScreenStay；安装目录内也有 Uninstall.exe 可双击卸载。
· 便携版：解压 ScreenStay-v1.5.3.zip，直接运行 ScreenStay.exe；
  包内 Uninstall.exe 可用于卸载便携版。
· 安装包未签名，若 SmartScreen 提示，请选择「更多信息 → 仍要运行」。

一、功能
--------
开启「自动防息屏」后：
  · 检测到音乐 / 视频正在播放  →  阻止屏幕关闭和电脑空闲睡眠（屏幕已关会自动点亮）
  · 没有播放                  →  恢复 Windows 默认电源管理（屏幕按电源计划正常关闭）
静音播放也算播放，同样保持常亮；播放停止后还会再保持 10 秒，避免切歌/缓冲时闪烁。

此外还支持：
  · WinUI 3 主界面（常规 / 主题 / 阻止休眠的程序 / 使用说明 / 关于）
  · 自动切换 Windows 浅色 / 深色主题（自定义时间、日出日落、跟随夜间模式）
  · 查看当前有哪些程序在阻止屏幕休眠（需要管理员权限）
  · 开机自动启动、弹窗提醒开关

二、托盘图标
------------
1. 单击图标：打开主界面。
2. 双击图标：快速开关自动防息屏。
3. 右键图标只有 4 项，当前状态在最上面：
     · 当前状态（只读）：自动防息屏未开启 / 已开启，无音视频播放 /
       已开启，检测到播放 / 已开启，播放暂停缓冲中
     · 自动防息屏（播放音视频时保持常亮）  —— 勾选 = 开启监测
     · 打开主页面                         —— 打开 WinUI 3 主界面
     · 退出                              —— 关闭程序并恢复系统默认电源管理
4. 图标状态（只保留显示器图标，用颜色区分）：
    红色显示器   = 已开启，检测到播放
    绿色显示器   = 已开启，无音视频播放 / 播放暂停缓冲中
    灰色显示器   = 自动防息屏未开启
   托盘图标悬停提示会显示与右键菜单相同的状态文字。

三、主界面（WinUI 3）
---------------------
左侧导航包含 5 个页面：
  · 常规：顶部显示「当前监测状态」（每 2 秒刷新）和「当前检测到的播放软件」，
          下方是自动防息屏开关、开机自动启动、弹窗提醒、查看电源请求入口
  · 主题：日间 / 夜间主题的 4 种自动切换方式
  · 阻止休眠的程序：获取系统电源请求（需要管理员权限）
  · 使用说明：本帮助
  · 关于：版本、开发者、路径与配置信息

主界面与托盘菜单双向同步：在主界面修改开关后，主程序约 3 秒内自动应用。
主界面只允许一个窗口，再次单击托盘图标会激活已打开的窗口。
窗口大小会自动适配屏幕与缩放比例（1080p / 4K 下都会以合适大小打开）。

四、自动切换日间/夜间主题
--------------------------
主界面 →「主题」→ 开启「自动切换日间/夜间主题」，切换方式有 4 种：
    1. 自定义时间：设置「日间开始」「夜间开始」两个固定时间；
    2. 日出日落（自动定位）：点「获取当前位置」，用 Windows 定位自动计算
       当地日出 / 日落时间；
    3. 日出日落（手动选择城市）：从内置城市列表中选择，按该城市经纬度计算；
    4. 跟随 Windows 夜间模式：夜间模式开启时用深色主题，关闭时用浅色主题
       （读取不到时自动回退到自定义时间）。

· 主题页没有「保存」按钮：修改切换方式、时间、城市等任何设置都会自动保存，
  开启自动切换后约 10~15 秒内生效。
· 日出日落采用近似算法（精度约 1~2 分钟）；极昼 / 极夜会回退固定时间。
· 自动定位需要开启 Windows 位置服务，并允许桌面应用访问位置；失败时可改用
  手动选择城市。
· 如果同时安装了 Auto Dark Mode 或 PowerToys Light Switch，两者会互相覆盖主题，
  请只保留一个自动主题工具。

五、阻止休眠的程序
------------------
主界面 →「阻止休眠的程序」→ 点「获取电源请求（需要管理员权限）」。
Windows 只允许管理员读取系统电源请求（powercfg /requests），因此会弹出 UAC，
点「是」即可。

· 默认用中文显示两类：
    「屏幕显示（阻止屏幕关闭）」—— 正在阻止熄屏的程序；
    「系统睡眠（阻止系统睡眠）」—— 正在阻止电脑睡眠的程序。
  只显示程序名称，方便理解。
· 需要排查时点「显示详细信息」，可查看原始 powercfg /requests 输出；再点一次隐藏。
· 「复制到剪贴板」会复制中文摘要和原始输出。

六、注意
--------
· 建议把程序放到固定位置（如 D:\Tools\ScreenStay\）后再开启开机自启；
  移动 exe 后请在主界面「常规」里重新开关一次「开机自动启动」。
· 本工具只阻止「系统空闲」导致的熄屏。手动关显示器、合盖、Win+L 锁屏仍按系统策略执行。
· 如果启用了屏幕保护程序，请到 设置 → 个性化 → 锁屏界面 → 屏幕保护程序 里设为「无」。
· 自动切换主题目前不切换壁纸，只切换浅色 / 深色主题。
· 想彻底卸载：主界面「常规」→ 关闭「开机自动启动」→ 托盘右键「退出」，再删除文件夹
  （配置在注册表 HKCU\Software\ScreenStay，可一并删除）。

七、其他
--------
· 更新记录：见 CHANGELOG.md
· 自检命令：ScreenStay.exe --selftest 报告.txt
· 源码：src\KeepAwake.cs、shared\（日出日落 / 夜间模式解析）

· WinUI 3 主界面源码：viewer\；重新编译：viewer\build-viewer.cmd（需要 .NET 8 SDK）

八、从源码构建与打包（Windows）
------------------------------
在项目根目录按顺序执行以下命令：
1. 主程序（Windows 自带 .NET Framework 4.x 的 csc.exe）：
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
   输出根目录 ScreenStay.exe。
2. WinUI 3 主界面（需要 .NET 8 SDK，首次还原 NuGet 包需要联网）：
   powershell -NoProfile -ExecutionPolicy Bypass -File .\viewer\build-viewer.ps1
   将 dotnet build 的 Release/win-x64 输出复制到 viewer-dist\。
   不是 dotnet publish；不要用 publish 替代，以免缺少 WinUI 的 PRI/XBF 文件。
   目标电脑需要 Windows App Runtime 2.6.5。
3. 安装器与便携包（使用 .NET Framework 4.x 的 csc.exe、WPF 程序集及
   PowerShell Compress-Archive）：
   powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1
   从 installer\Uninstall.cs 编译卸载程序；默认输出 dist\Uninstall.exe、
   dist\ScreenStay-Setup-1.5.3.exe、dist\ScreenStay-v1.5.3.zip。
   只有第 3 步生成卸载程序与发布包，安装包和便携包都包含 Uninstall.exe；
   便携包在安装器编译成功后才生成。

第 3 步不会自动重建前两部分，仅检查现有主程序和 Viewer.exe 是否存在，
不会确认产物是否最新、完整。打包前应重新运行前两步，避免使用旧产物。
viewer-dist\ 是构建产物而非源码，可以从源码包排除；保留 src\KeepAwake.cs、
shared\、viewer\、installer\、assets\、tools\、构建脚本、清单及说明文件。
排除产物后，打包前必须先重建主程序和 Viewer。仅使用托盘时可不构建 Viewer，
但当前安装器/便携包脚本要求 Viewer 产物存在。以上为流程说明，未验证实际构建成功。
